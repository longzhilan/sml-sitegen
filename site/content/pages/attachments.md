## 总原则

仓库只收**图片等小文件**；大文件、固件、数据集一律用外链，由作者自己提供。
理由：仓库会随时间膨胀，而外链的责任边界清楚。

## 入库的图片

- 放在文章同目录的 `assets/` 下，正文用相对路径引用（`![说明](assets/xxx.png)`）；
- 类型限于 `png / jpg / jpeg / webp / gif / svg`；
- 单张不超过 **2 MB**，单篇不超过 **20 张**（构建会检查，超限直接报错）；
- 发布前请清除照片的 EXIF 地理信息。

## 外链附件

- 必须是 `http(s)` 链接，并写名称、类型与体积说明（`attachments` 字段，`kind: link`）；
- 网盘类写清提取码与有效期；
- 链路失效由作者负责，站点只负责展示。

## 审核项

| 项 | 要求 |
|---|---|
| 版权 | 引用他人图表必须标出处；不放大段未授权转载 |
| 安全 | 不接受可执行文件与来历不明的固件 |
| 隐私 | 截图抹掉密钥、手机号、内部地址、真实姓名 |
| 命名 | `<短名>-<序号>-<语义名>.<扩展名>` |

## 附件的展示

图片随文章一起渲染；外链附件在文章底部列出（名称 / 类型 / 体积），构建期会校验链接格式与必填字段。
